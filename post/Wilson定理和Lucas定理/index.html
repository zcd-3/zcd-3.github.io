Wilson定理

对于自然数n>1n>1n>1,当且仅当nnn是素数时,(n−1)!≡−1(modn)(n-1)! \equiv -1\pmod{n}(n−1)!≡−1(modn).

证明：先证对素数ppp有(p−1)!≡−1(modp)(p-1)!\equiv -1 \pmod{p}(p−1)!≡−1(modp).
p=2,3p=2,3p=2,3时显然，当p>3p>3p>3时，Fp:=Z/pZ\mathbb{F}_{p}:=\mathbb{Z}/p\mathbb{Z}Fp​:=Z/pZ为域，非零元皆有乘法逆元.
考虑a2≡1(modp)⇒0≡a2−1≡(a+1)(a−1)(modp)⇒a=1,p−1a^{2}\equiv 1\pmod{p} \Rightarrow 0 \equiv a^{2}-1\equiv(a+1)(a-1) \pmod{p}\Rightarrow a=1,p-1a2≡1(modp)⇒0≡a2−1≡(a+1)(a−1)(modp)⇒a=1,p−1
故Fp∖{0,1,p−1}\mathbb{F}_{p} \smallsetminus \{0,1,p-1\}Fp​∖{0,1,p−1}中所有元素乘积为111，进而有Fp\mathbb{F}_{p}Fp​中所有非零元素之积为−1-1−1

另一方面，当nnn为合数时，假设(n−1)!≡−1(modn)(n-1)!\equiv -1 \pmod{n}(n−1)!≡−1(modn)，即存在整数kkk使得(n−1)≠kn−1(n-1)\neq kn-1(n−1)=kn−1成立。因为nnn是合数，必然存在素数p<np<np<n使得n=pmn=pmn=pm，所以(n−1)!=kpm−1≡−1(modp)(n-1)! =kpm-1\equiv -1 \pmod{p}(n−1)!=kpm−1≡−1(modp)。但乘积(n−1)!(n-1)!(n−1)!中必然已出现过ppp，故而一定有(n−1)!≡0(modp)(n-1)!\equiv 0 \pmod{p}(n−1)!≡0(modp)，矛盾。
